FS-DVS: A Frequency-Selective Dynamic Visual Sensing Paradigm

Feiyu Ji, Xiaokang Yang, Xiaoyun Yuan✉

arXiv:2606.06856 (Submitted 5 Jun 2026), cs.CV

Abstract

Dynamic vision sensors (DVS) capture sparse asynchronous intensity changes but conventional per-pixel triggering often misses weak structural details because spatial context is ignored. FS-DVS adds a learnable spatial filter before event triggering, inspired by retinal ganglion cell aggregation, and learns it end-to-end with downstream tasks. The filter naturally converges to center-surround mid-frequency emphasis matching human contrast sensitivity, improving structural completeness and noise resilience for detection, recognition, and segmentation.

Key idea

  • Spatial filter is learned directly before event generation.
  • Differentiable DVS simulation enables task-aware optimization.
  • Learned filters converge to CSF-like mid-frequency selectivity.
