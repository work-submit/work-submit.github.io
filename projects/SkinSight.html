What Is SkinSight?

SkinSight is a skin-conformal camera array for deformable surfaces. Instead of stretching the optical path itself, it keeps the imaging modules rigid and embeds them in a soft substrate, so the array can conform to skin or soft robots while preserving useful visual detail.

How Does It Work?

Compact CMOS imager nodes are connected by serpentine interconnects inside an elastic substrate. The soft region absorbs bending, twisting, and stretching, while each rigid node keeps its local camera geometry stable.

What Can It Do?

When worn on the palm, SkinSight turns the hand into an active visual interface. It captures views hidden from the user, reconstructs the scene, and registers the result into an augmented-reality view.
