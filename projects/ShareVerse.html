Abstract

ShareVerse is a video generation framework for multi-agent shared world modeling. It addresses the lack of unified shared-world construction in existing video generation systems by combining large video-model priors with multi-agent interaction. The framework builds a large-scale CARLA-based dataset with diverse scenes, weather conditions, interactive trajectories, paired multi-view videos, and camera data; uses spatial concatenation to model broader environments while preserving multi-view geometric consistency; and introduces cross-agent attention blocks to transmit spatiotemporal information between agents. ShareVerse supports 49-frame large-scale video generation and maintains consistency across overlapping and non-overlapping regions.

Framework Overview

ShareVerse couples independent-agent video generation through shared spatial context and cross-agent attention. A global spatiotemporal memory cache preserves environmental permanence during asynchronous revisitation, enabling agents to revisit previously generated areas without drifting away from the shared world.

Dataset

The ShareVerse dataset is built on CARLA simulation and covers diverse scene layouts, weather conditions, and interactive multi-agent trajectories. Each sample includes paired multi-view videos and camera metadata for shared-world video generation.
