FS-DVS: A Frequency-Selective Dynamic Visual Sensing Paradigm

Abstract

Dynamic vision sensors (DVS) capture sparse asynchronous intensity changes, but conventional per-pixel triggering often misses weak structural details because spatial context is ignored. FS-DVS introduces a learnable spatial filter before event triggering, inspired by retinal ganglion cell aggregation, and optimizes it end-to-end with downstream tasks. The learned filter naturally converges to center-surround mid-frequency emphasis that matches human contrast sensitivity, improving structural completeness and noise resilience for detection, recognition, and segmentation.

Framework Overview

FS-DVS places a learnable spatial filtering stage before event generation. Instead of triggering each pixel independently, the sensor response is shaped by neighboring visual context, allowing weak but meaningful structures to contribute to the event stream. A differentiable DVS simulator makes the full sensing pipeline trainable, so the frequency-selective filter can be optimized directly for target vision tasks.

Key Idea

The core idea is to learn what frequency components should be emphasized before asynchronous event triggering. The resulting filters exhibit CSF-like mid-frequency selectivity and center-surround patterns, providing more complete structures while suppressing unreliable noise responses.

  • Spatial filtering is learned directly before event generation.
  • Differentiable DVS simulation enables task-aware optimization.
  • Learned filters converge to contrast-sensitivity-like mid-frequency selectivity.

Experimental Results

Experiments on detection, recognition, and segmentation demonstrate that FS-DVS improves structural completeness and robustness compared with conventional event triggering. By using learned frequency-selective sensing rather than fixed per-pixel thresholds alone, the generated event representations retain more task-relevant visual information.
